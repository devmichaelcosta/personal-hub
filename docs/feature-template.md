# Template De Feature

Use este modelo ao pedir uma nova feature ao Codex.

## Objetivo

Descreva em uma frase o resultado esperado.

## Usuario

Quem usa esta feature e em qual contexto?

## Fluxo esperado

Liste os passos principais do usuario.

## Regras

Quais regras de negocio devem ser respeitadas?

## Interface

Indique se a mudanca afeta:

- Tela MVC/Razor
- API
- Dominio
- Banco de dados
- Jobs, seeds ou configuracao

## Dados

Quais campos, filtros, estados ou relacoes precisam existir?

## Criterios de aceite

- O usuario consegue concluir o fluxo principal.
- Erros previsiveis mostram mensagem clara.
- A regra principal tem teste automatizado quando couber.
- A mudanca nao quebra fluxos existentes.

## Testes esperados

Indique os cenarios que precisam ser testados, incluindo casos felizes e casos de erro.

## Fora de escopo

Liste explicitamente o que nao deve ser alterado nesta rodada.
